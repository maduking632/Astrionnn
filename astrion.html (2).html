Primeiro MVP

ASTRION FLOW

Começamos simples e poderoso: uma plataforma onde a empresa cria automações do tipo SE acontecer isso → ENTÃO faça aquilo.

Exemplo: Novo cliente → salvar dados → enviar mensagem → avisar funcionário.

Depois evoluímos: a IA analisa, toma decisões dentro das regras e executa ações. Assim a ASTRION vira uma empresa realmente tecnológica e escalável — não apenas uma agência que faz sites.

// Automação ASTRION FLOW
SE novo_cliente() {
  salvar_dados(cliente);
  enviar_mensagem(
    "Olá! Recebemos seu cadastro."
  );
  avisar_equipe(cliente);
}
// Depois: IA analisa e decide
SE evento() {
  const decisao = IA.analisar(regras);
  executar(decisao);
}
